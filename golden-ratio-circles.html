Goldener-Schnitt-Kreise auf einer Ebene

Kreise mit Flaechen im Goldenen Schnitt liegen auf einer gemeinsamen Auflage-Ebene und beruehren sich paarweise. Wie waechst der Graph der Mittelpunkte?

Flaechenverhaeltnis:
Fn / Fn+1 = Fn+1 / (Fn+1 + Fn) = 1/φ ≈ 0.618
Radienverhaeltnis: rn+1 / rn = √φ ≈ 1.2720

Ergebnis: Die Mittelpunkte liegen auf einer Geraden!

Jeder Kreis Ki mit Radius ri hat seinen Mittelpunkt auf Hoehe hi = ri. Zwei benachbarte Kreise beruehren sich, also gilt fuer den Mittelpunktsabstand:

d(Ki, Ki+1) = ri + ri+1

Der horizontale Abstand ergibt sich aus dem Satz des Pythagoras:

Δx = √(d² − Δh²) = √((ri+ri+1)² − (ri+1−ri)²) = 2√(ri · ri+1)

Die Steigung zwischen zwei aufeinanderfolgenden Mittelpunkten:

Δh / Δx = (ri+1 − ri) / (2√(ri · ri+1)) = (√φ − 1) / (2 · φ1/4) ≈ 0.12060 = const.

Da die Steigung fuer jedes Paar identisch ist, liegen alle Mittelpunkte exakt auf einer Geraden.
Die Potenz ist 1 (linear): h(x) = m · x + r0   mit Steigung m = (√φ − 1) / (2φ1/4) ≈ 0.1206, entsprechend einem Winkel von α ≈ 6.88°.

Kreisdaten (Goldener Schnitt)

i ri hi = ri xi Δy/Δx

Verallgemeinerung: Gilt das nur fuer den Goldenen Schnitt?

Nein! Es gilt fuer JEDES konstante Flaechenverhaeltnis.

Fuer beliebige Kreise, deren Radien eine geometrische Folge bilden (ri+1 = q · ri mit konstantem q > 1), vereinfacht sich die Steigung zu:

m(q) = Δh/Δx = (q − 1) / (2√q)

Der entscheidende Punkt: ri kuerzt sich vollstaendig heraus! Die Steigung haengt nur vom Verhaeltnis q ab, nicht vom Index i. Daher liegen die Mittelpunkte fuer jedes q immer auf einer exakten Geraden.

Der Goldene Schnitt ist also kein Sonderfall — er liefert lediglich eine bestimmte Steigung unter unendlich vielen moeglichen.
